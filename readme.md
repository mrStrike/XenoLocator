# XenoLocator — портативный 2.4G «детектор движения» в стиле USCSS

**XenoLocator** — это прошивка для ES3C28P на ESP32-S3, которая превращает плату с экраном
ILI9341 и тачскрином в атмосферный «локатор ксеноморфов» из вселенной «Чужого».
Устройство сканирует Wi-Fi-эфир, выбирает цель по BSSID и отслеживает изменение
уровня сигнала (RSSI), отображая приближение/удаление цели на радарном экране
с фосфорно-зелёной эстетикой, звуковым сонаром и фоновой музыкой.

> ⚠️ Это **декоративное/развлекательное** устройство. Оно **не измеряет
> расстояние и не определяет направление** на цель. Радиус и пеленг на радаре —
> художественная интерпретация RSSI, а не физические измерения.

---

## Возможности

- 📡 **Сканирование Wi-Fi** — список видимых сетей с RSSI, каналом и BSSID, постраничный вывод.
- 🎯 **Выбор цели** — тап по сети фиксирует её MAC-адрес как «цель».
- 📶 **Трекинг RSSI** — периодический опрос выбранной цели, оценка тренда:
  «ПРИБЛИЖАЕТЕСЬ», «ОТДАЛЯЕТЕСЬ», «БЕЗ ИЗМЕНЕНИЙ», «ЦЕЛЬ ПОТЕРЯНА».
- 🖥 **Радарный экран** — анимированные фосфорные кольца, «контакты» соседних сетей
  и маркер цели. Рендер оптимизирован: во время анимации обновляется только
  область радара (158×85), а не весь кадр.
- 🔤 **Кириллица на экране** — собственный 5×7 пиксельный шрифт для заглавных
  русских букв (включая Ё), плюс встроенный шрифт GFX для латиницы/цифр.
- 🔊 **Звук** — синтезированный «сонарный» пинг (I2S + ES8311), частота пинга
  зависит от силы сигнала; громкость регулируется кнопками на экране (10 шагов).
- 🎵 **Фоновая музыка** — MP3 из PROGMEM, декодируется на лету через
  `AudioGeneratorMP3`, микшируется с пингом в реальном времени.
- 🧵 **Многозадачность на FreeRTOS** — Wi-Fi-скан, тач, UI, аудио и музыка
  работают в отдельных задачах, привязанных к ядрам; обмен через очереди,
  без гонок за общие `String` между ядрами.
- 🖱 **Кастомный тач** — драйвер FT6236 (I2C 0x38) с инверсией осей под
  ориентацию панели, опрос в отдельной задаче.
- 🚀 **Boot-анимация** — семисекундная заставка «ИНИЦИАЛИЗАЦИЯ M314» с
  прогресс-баром и проверкой подсистем (дисплей, сенсор, аудио, скан).

## Аппаратная платформа

| Компонент        | Модель / распиновка |
|------------------|---------------------|
| MCU              | ESP32-S3            |
| Дисплей          | ILI9341, 240×320, SPI |
| Тачскрин         | FT6236, I2C (0x38)  |
| Аудиокодек       | ES8311, I2C (0x18) + I2S |
| I2S (аудио)      | MCLK=4, BCLK=5, WS=7, DOUT=8 |
| SPI (дисплей)    | SCLK=12, MOSI=11, MISO=13, DC=46, CS=10 |
| I2C (тач/кодек)  | SDA=16, SCL=15      |
| Управление       | GPIO 1 (индикатор), GPIO 45 (подсветка), GPIO 18 (сброс кодека) |

> Пины соответствуют конфигурации `LGFX` и `beginLocatorAudio()` в коде.
> При сборке на другой плате их нужно изменить.

## Структура проекта


**Главные сущности в `main.ino`:**

- `LGFX` — конфигурация LovyanGFX под ILI9341 (SPI2, DMA, swap bytes).
- `ui` — `GFXcanvas16` 240×320, весь UI рисуется в буфер и пушится одним `pushImage`.
- `ru[33][7][6]` — таблица кириллических глифов 5×7.
- `scanTask` / `requestScan` / `tickScanResults` — асинхронный Wi-Fi-сканер.
- `touchTask` / `touched` / `uiStep` — опрос тача и обработка нажатий.
- `drawRadar` / `pushRadar` — анимация радара с частичным обновлением экрана.
- `startupIntro` — boot-заставка.

**`locator_audio.h`:**

- `prepareSonar()` — предрасчёт сонарной волны (1450 Гц, атака 4 мс, эхо через 85 мс).
- `pingTask` — микширование сонара и MP3, вывод в I2S.
- `musicTask` — декодирование MP3 из PROGMEM через `AudioGeneratorMP3`.
- `es8311_init()` — инициализация кодека по проверенной таблице регистров.
- `beginLocatorAudio()` — единая точка запуска аудио; поддерживает и новый
  (ESP-IDF 5+, `driver/i2s_std.h`), и legacy (`driver/i2s.h`) API.

## Сборка и прошивка

1. Установите **Arduino IDE 2.x** (или `arduino-cli`) с ядром **ESP32 (ESP-IDF 5+)**.
2. Установите библиотеки:
   - **LovyanGFX**
   - **Adafruit GFX Library**
   - **ESP32-audioI2S** (или совместимый `AudioGeneratorMP3`, `AudioFileSourcePROGMEM`, `AudioOutput`)
3. Откройте `main.ino`, выберите плату **ESP32S3 Dev Module**.
4. Настройки сборки (рекомендуемые):
   - Flash Size: **16MB**
   - Partition Scheme: **Huge APP (3MB No OTA)** или больше — прошивка крупная из-за MP3.
   - PSRAM: **Enabled** 
   - CPU Frequency: **240 MHz**
5. Прошейте плату.

> MP3-данные (`music_*.inc`) занимают ~9 МБ исходников и вкомпилируются в
> прошивку. Убедитесь, что выбранная схема разделов вмещает ваш бинарник.

## Использование

1. При включении устройство показывает **boot-анимацию** (~7.6 с) и ждёт тапа
   по экрану для входа.
2. На экране **«ВЫБЕРИТЕ ЦЕЛЬ»** отображается список Wi-Fi-сетей.
   - Тап по сети → переход в режим трекинга.
   - Кнопка **«СЛЕДУЮЩАЯ СТРАНИЦА / ОБНОВИТЬ СПИСОК»** — листание и пересканирование.
3. В режиме трекинга:
   - Радар показывает цель и соседние сети.
   - Тренд и примерная «дистанция» обновляются каждые ~3 с.
   - Кнопки **+ / −** справа регулируют громкость пинга.
   - Кнопка **«< ВЫБРАТЬ ДРУГУЮ СЕТЬ»** — возврат к списку.

## Как это работает (кратко)

- **Сканирование** выполняется в отдельной задаче `scanTask` (ядро 0), чтобы
  не блокировать отрисовку. Результаты передаются через `QueueHandle_t`
  (`ScanRequest` / `ScanResult`), без общих `String` между ядрами.
- **RSSI → частота пинга**: чем сильнее сигнал, тем чаще сонар
  (`pingPeriod = 1800 − f(RSSI)`, ограничено 0…1500 мс).
- **Радар**: кольца, сетка и контакты рисуются в `GFXcanvas16`, затем
  копируются в отдельный буфер `radarPixels` и пушатся одним `pushImage`
  только для области 158×85 — так анимация не перерисовывает весь экран.
- **Пеленг контактов** — псевдослучайный, стабильный для каждого BSSID
  (хеш FNV-1a от MAC). Радиус зависит от RSSI. Это **декор**, а не измерение.
- **Аудио**: `pingTask` микширует предрасчитанную сонарную волну с
  декодированным MP3 и пишет блоки 256×2 сэмплов в I2S. Кодек ES8311
  инициализируется по фиксированной таблице регистров.
- **Тач**: `touchTask` опрашивает FT6236 каждые 5 мс, инвертирует оси под
  ориентацию панели и кладёт события в очередь; UI обрабатывает их без
  блокировки SPI-передач дисплея.

## Известные ограничения

- Устройство **не измеряет расстояние и направление** — только RSSI.
- Список сетей ограничен 30 записями (см. `aps[30]`, `ScanEntry entries[30]`).
- MP3 вкомпилирован в PROGMEM — размер прошивки большой; при нехватке места
  уменьшите число `music_*.inc` или используйте SPIFFS/SD.
- Пины и таблица регистров ES8311 заточены под конкретную плату —
  при переносе на другую аппаратуру их нужно править.
- Кириллический шрифт — только заглавные буквы; строчные преобразуются
  в заглавные на лету.
